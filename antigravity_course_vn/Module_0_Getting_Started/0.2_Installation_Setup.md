# 0.2 Cài đặt & Thiết lập Antigravity dễ dàng

## Thông tin chung
- **Thời gian hoàn thành:** 15 phút
- **Yêu cầu:** Máy tính Windows hoặc Mac
- **Mục tiêu:** Cài đặt xong phần mềm và sẵn sàng sử dụng.

## Tổng quan

Đừng lo lắng, việc cài đặt Antigravity đơn giản như cài Zalo hay Microsoft Office thôi. Bạn không cần phải biết code hay cấu hình server gì cả.

## Hướng dẫn cài đặt nhanh

### Dành cho Windows
1.  **Tải xuống:** Truy cập [antigravity.google/download](https://antigravity.google/download) và chọn **Windows**.
2.  **Cài đặt:** Mở file `.exe` vừa tải về. Nhấn "Next" liên tục cho đến khi hoàn tất.
3.  **Khởi động:** Click đúp vào biểu tượng Antigravity (hình phi hành gia/tên lửa) trên màn hình Desktop.

### Dành cho Mac
1.  **Tải xuống:** Truy cập trang chủ và chọn **Mac (Apple Silicon)** nếu dùng máy chip M1/M2/M3, hoặc **Intel** nếu dùng máy cũ hơn.
2.  **Cài đặt:** Kéo biểu tượng phần mềm vào thư mục Applications.
3.  **Khởi động:** Tìm Antigravity trong Launchpad và mở lên.

## Làm quen Giao diện ban đầu

Khi mở lên lần đầu, bạn sẽ thấy một giao diện rất giống phần mềm chat (như Messenger/Slack) kết hợp với trình soạn thảo văn bản (Word).

### 1. Đăng nhập (Tùy chọn)
Bạn có thể đăng nhập bằng Google để đồng bộ cài đặt. Nếu không, bấm "Skip" để dùng luôn.

### 2. Chọn Giao diện (Theme)
- **Light Mode (Sáng):** Giống Word/Excel, dễ nhìn văn bản.
- **Dark Mode (Tối):** Dịu mắt, dân công nghệ hay dùng.
*Khuyên dùng:* Chọn Light Mode cho quen thuộc trước.

### 3. Kiểm tra Cửa sổ lệnh (Terminal)
Ở dưới cùng có một ô để gõ lệnh. Đừng sợ nó! Với Antigravity, bạn chỉ cần gõ tiếng Việt hoặc tiếng Anh đơn giản vào đó, không cần gõ lệnh phức tạp đâu.

## Tạo Thư mục làm việc (Workspace)

Để bắt đầu học, chúng ta cần một "bàn làm việc" sạch sẽ.

1. Tại màn hình chính, chọn **"Open Folder"** (Mở thư mục).
2. Tạo một thư mục mới trong máy bạn, đặt tên là `Khoa_Hoc_Antigravity`.
3. Chọn thư mục đó.

## Xử lý sự cố thường gặp

**"Máy báo phần mềm không an toàn (Security Warning)"**
- Trên Windows: Bấm "More Info" -> "Run Anyway".
- Trên Mac: Vào System Settings -> Privacy & Security -> Allow Antigravity.
*Lý do:* Vì đây là phần mềm mới, đôi khi hệ điều hành sẽ cảnh báo "nhầm". Phần mềm từ Google nên bạn yên tâm tuyệt đối.

**"Không gõ được tiếng Việt"**
Đảm bảo bạn đã bật Unikey (hoặc bộ gõ tiếng Việt) ở chế độ "Run as Administrator" nếu bị lỗi. Antigravity hỗ trợ tiếng Việt rất tốt.

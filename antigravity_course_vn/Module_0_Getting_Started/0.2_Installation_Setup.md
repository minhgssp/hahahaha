# 0.2 Cài đặt & Thiết lập Antigravity (Từng bước dễ dàng)

## 🎯 Thông tin chung
- **Thời gian hoàn thành:** 10 - 15 phút
- **Yêu cầu:** Máy tính chạy hệ điều hành Windows hoặc macOS (Laptop hoặc PC).
- **Mục tiêu:** Cài đặt xong phần mềm Antigravity và sẵn sàng bắt đầu làm việc.

---

## 🛠️ Hướng dẫn Cài đặt Nhanh

Đừng lo lắng, việc cài đặt Antigravity đơn giản như cài đặt Zalo, Word hay trình duyệt Chrome. Bạn hoàn toàn không cần biết kỹ thuật lập trình.

![Trang tải phần mềm và quá trình cài đặt](../assets/screenshots/01_download_install.png)
> 📸 *[Hướng dẫn chụp màn hình: Trang web tải Antigravity kèm nút bấm tải cho Windows / Mac và cửa sổ cài đặt đơn giản].*

### 1. Dành cho máy tính Windows
1. **Tải file cài đặt:** Mở trình duyệt và truy cập trang tải phần mềm Antigravity, bấm nút **Download for Windows**.
2. **Tiến hành cài đặt:** Mở file vừa tải về (thường có đuôi `.exe` trong thư mục `Downloads`).
3. **Thao tác:** Bấm **Next** theo hướng dẫn trên màn hình cho đến khi hoàn tất, sau đó bấm **Finish**.
4. **Khởi động:** Nhìn trên màn hình chính (Desktop), click đúp vào biểu tượng Antigravity để mở phần mềm.

### 2. Dành cho máy tính Mac (Apple Silicon / Intel)
1. **Tải file cài đặt:** Truy cập trang tải và chọn đúng phiên bản:
   - Chọn **Mac (Apple Silicon)** nếu máy bạn dùng chip M1, M2, M3...
   - Chọn **Mac (Intel)** nếu máy bạn là các dòng Macbook đời cũ hơn.
2. **Cài đặt:** Mở file `.dmg` vừa tải về, kéo biểu tượng Antigravity thả vào thư mục **Applications (Ứng dụng)**.
3. **Khởi động:** Mở Launchpad hoặc Spotlight (`Cmd + Space`), gõ `Antigravity` và nhấn Enter.

## 🖥️ Màn hình Khởi động Đầu tiên

Khi bạn mở Antigravity lần đầu, phần mềm sẽ hiển thị màn hình chào mừng trực quan:

![Màn hình chào mừng đầu tiên của Antigravity](../assets/screenshots/02_first_open_screen.png)
> 📸 *[Hướng dẫn chụp màn hình: Giao diện mở lên lần đầu tiên, chỉ rõ nút Open Folder ở giữa màn hình và thanh menu phía trên].*

### 1. Đăng nhập tài khoản
- Bạn có thể đăng nhập bằng tài khoản Google của mình để lưu các cài đặt cá nhân.
- Hoặc bạn có thể bấm **Skip** (Bỏ qua) để bắt đầu sử dụng ngay lập tức mà không gặp bất kỳ trở ngại nào.

### 2. Chọn giao diện Sáng / Tối (Theme)
- **Giao diện sáng (Light Mode):** Rất quen thuộc như khi làm việc trên Word hay Google Docs, chữ đen trên nền trắng rõ nét.
- **Giao diện tối (Dark Mode):** Nền tối dịu mắt, phù hợp khi làm việc buổi tối.
> *Lời khuyên cho người mới:* Hãy chọn giao diện mà bạn cảm thấy mắt mình thoải mái nhất!

## ❓ Xử lý Sự cố Thường gặp

**1. Máy tính hiển thị cảnh báo "Windows protected your PC" (Cảnh báo bảo mật)?**
- *Cách xử lý:* Đây là cảnh báo tiêu chuẩn của Windows với các phần mềm mới. Bạn chỉ cần bấm vào dòng chữ **More info** (Thông tin thêm) → chọn **Run anyway** (Vẫn chạy) là xong.

**2. Gõ tiếng Việt có bị lỗi font không?**
- Antigravity hỗ trợ chuẩn gõ tiếng Việt Unicode hoàn hảo. Bạn chỉ cần dùng bộ gõ Unikey hoặc EVKey bình thường (bảng mã Unicode, kiểu gõ Telex/VNI).

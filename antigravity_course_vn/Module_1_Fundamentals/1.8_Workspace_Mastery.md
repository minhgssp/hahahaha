## 1. Workspace = Thư mục trên Ổ cứng

Đừng nghĩ Antigravity là phần mềm bí ẩn. Nó chỉ là "kính lúp" soi vào ổ cứng:
- Xóa file ở đây → Mất file trên Windows.
- Copy file vào thư mục Windows → Nó hiện lên ở đây.
- Workspace chỉ là **đường dẫn** đến một thư mục trên máy.

**Thử ngay:** Mở Windows Explorer, tìm thư mục `antigravity_course_vn` và xác nhận nó nằm ở đâu.

---

## 2. Artifacts — Bộ nhớ của Dự án

Khi AI làm việc trong Planning mode, nó tạo ra các file đặc biệt:

| Artifact                 | Vai trò                                     |
| ------------------------ | ------------------------------------------- |
| `task.md`                | To-do list — theo dõi tiến độ               |
| `walkthrough.md`         | Nhật ký công việc — ghi lại những gì đã làm |
| `implementation_plan.md` | Bản kế hoạch — trước khi thực hiện          |

Các file này nằm trong thư mục `brain/` của Antigravity. Bạn có thể yêu cầu AI "Cho tôi xem task.md" bất cứ lúc nào.

---

## 3. An toàn Dữ liệu — Backup & Turbo

Là PM, bạn phải quản lý rủi ro:
- **Backup:** Trước khi ra lệnh "Sửa toàn bộ dự án", hãy copy folder ra chỗ khác.
- **Turbo Mode (Always Run):** AI tự động thực thi không cần duyệt từng bước. Nhanh nhưng nguy hiểm.

**Lời khuyên:** Chỉ dùng Always Run cho tác vụ **tạo mới** (Create). Hạn chế cho **sửa/xóa** (Update/Delete) nếu chưa backup.

---

## 4. Đồng bộ Dữ liệu giữa Nhiều Thiết bị (Nâng cao)

Nếu bạn dùng **nhiều máy tính** hoặc muốn **chia sẻ workspace với đồng nghiệp**:

### Phương pháp 1: Cloud Sync (Cá nhân)
- Đặt workspace vào **OneDrive, Google Drive, hoặc Dropbox**
- Ví dụ: `C:\Users\ban\OneDrive\PM_Workspace\`
- Antigravity trên máy nào cũng mở cùng thư mục → Đồng bộ tự động
- ⚠️ **Lưu ý:** Tránh 2 máy mở cùng lúc → xung đột file

### Phương pháp 2: Git (Đội nhóm — Chuyên nghiệp)
- Dùng **Git + GitHub/GitLab** để quản lý phiên bản và chia sẻ
- Mỗi người clone cùng repository → Mỗi người có workspace riêng
- Push/Pull để đồng bộ. Lợi thế: lịch sử thay đổi, xử lý xung đột

### Phương pháp 3: Copy thủ công (Đơn giản)
- Zip thư mục → Gửi qua email/Zalo/Slack
- Phù hợp khi chia sẻ một lần, không cần đồng bộ liên tục

> **Quan trọng:** Workspace chỉ là thư mục trên ổ cứng. AI không lưu gì trên cloud.  
> Rules, Skills, Knowledge **gắn liền với máy**, không tự đồng bộ theo workspace.

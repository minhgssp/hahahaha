## Phần 1: Hai Giao diện — Agent Manager vs Editor

Antigravity có **2 giao diện** hoàn toàn khác nhau. Hiểu sự khác biệt này rất quan trọng:

|                       | Agent Manager                                          | Editor                                                   |
| --------------------- | ------------------------------------------------------ | -------------------------------------------------------- |
| **Vai trò**    | "Sảnh chính" — Điều phối & Quản lý             | "Phòng làm việc" — Thao tác trực tiếp với file   |
| **Khi mở**     | Thấy đầu tiên khi khởi động                     | Click "Open Editor" để vào                            |
| **Chức năng** | Quản lý agents, gọi workflow tổng quan, cài đặt | Mở file, soạn thảo, chat với AI theo ngữ cảnh file |
| **Cấu trúc**  | Giao diện Chat + Cài đặt                           | File Explorer (trái) + Editor (giữa) + Chat (phải)    |
| **Lệnh slash** | ✅ Hoạt động (Gọi workflow, hỏi đáp chung)      | ✅ Hoạt động (Tương tác sâu với file đang mở)  |

**Quy tắc:** Mặc dù bạn CÓ THỂ chát và ra lệnh ở Agent Manager, nhưng khi cần chỉnh sửa file chi tiết thì hãy luôn vào **Editor**.

---

## Phần 2: Ba khu vực chính của Editor

### 1. File Explorer (Sidebar bên trái) - "Kho nguyên liệu"

Nơi chứa toàn bộ tài liệu công ty TaskFlow.

- **Mở/Đóng:** Bấm vào biểu tượng Explorer ở góc trái trên cùng.
- **Điều hướng:** Click vào thư mục để mở/đóng, click vào file để xem nội dung.
- **Lưu ý:** Antigravity nhìn thấy mọi thứ ở đây. Hãy giữ nó gọn gàng.

### 2. Vùng Soạn thảo (Chính giữa) - "Bàn làm việc"

Nơi hiển thị nội dung file khi bạn click vào.

- Xem và chỉnh sửa file trực tiếp.
- Xem trước Markdown bằng **Ctrl+Shift+V** — hiển thị đẹp hơn, **dễ đọc PRD**.

### 3. Khung Chat (Bên phải/Dưới) - "Trợ lý Chỉ huy"

Nơi bạn trò chuyện và ra lệnh cho AI.

- **Gõ lệnh:** Sử dụng tiếng Việt tự nhiên.
- **Slash Command (`/`):** Gõ dấu `/` để gọi workflow.
- **@ Mention (`@`):** Gõ dấu `@` để tham chiếu file hoặc thư mục — **kỹ năng quan trọng nhất!**

---

## Phần 3: Thêm Thư mục vào Workspace (Add Folder)

Bạn có thể **thêm nhiều thư mục** vào cùng một workspace!

**Cách làm:** Vào menu **File** → **Add Folder to Workspace...** → chọn thư mục.

**Ứng dụng PM:**

- Thêm thư mục "Báo cáo Q4" để AI phân tích song song với dự án.
- Thêm thư mục "Quy trình công ty" để AI tham chiếu khi viết PRD.
- Làm việc với nhiều dự án trong cùng một workspace.

> **Lưu ý:** Thư mục thêm vào chỉ tồn tại trong phiên hiện tại.

## Phần 4: @ Mention - Kỹ năng #1

@ mention là cách bạn tham chiếu tài liệu trong 90% thời gian làm việc.

### Mention thư mục

> "Tóm tắt các thông tin chính từ @company-context"

### Mention file

> "Đọc @Sales_Data.csv và tìm sản phẩm bán chạy nhất."

## Phần 5: Hai Chế độ Thực thi

### Fast Mode (Tốc độ)

- AI phản hồi trực tiếp, nhanh. Dùng cho phần lớn khóa học.

### Planning Mode (Lập kế hoạch)

- AI tạo kế hoạch trước khi hành động. Sẽ học kỹ ở **Module 1.5**.

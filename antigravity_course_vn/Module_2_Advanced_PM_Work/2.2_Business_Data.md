# 2.2 Phân tích Dữ liệu (Data Analysis)

## Thông tin chung
- **Thời gian hoàn thành:** 40-50 phút
- **Yêu cầu:** Module 2.1 hoặc đã quen với @ mentions
- **Bắt đầu:** Chạy lệnh `/start-2-2` trong Antigravity.

## Tổng quan

Module dày nhất khóa học. Bạn sẽ xử lý **4 bộ dữ liệu thực** — từ bảng doanh số 21 dòng đến phễu chuyển đổi 10.000 users — và xuất ra báo cáo HTML chuyên nghiệp. Không cần Excel, không cần VLOOKUP.

**Điểm chính:** Antigravity biến bạn từ "người đọc bảng tính" thành "người kể câu chuyện bằng dữ liệu".

---

## Chuỗi Phân tích 5 Phần

### Phần 1: Doanh số Cơ bản (21 dòng)
**File:** `Sales_Data.csv`

Khởi động bằng dữ liệu dễ hiểu. Hỏi AI:
- Tổng doanh thu, lợi nhuận, ai bán tốt nhất?
- Vùng nào yếu? Tại sao? (Chẩn đoán)
- Vẽ biểu đồ cột so sánh các vùng.

**Kỹ năng Antigravity luyện:** @ mention file CSV, ra lệnh tiếng Việt, vẽ biểu đồ.

### Phần 2: Phân tích Khảo sát (800 phản hồi)
**File:** `user-survey-responses.csv`

Đây là dữ liệu **định tính** (qualitative) — thứ mà Excel rất khó xử lý:
- Phân nhóm 800 phản hồi theo `feature_request` → đếm từng nhóm.
- Phân tích NPS theo `company_size` → doanh nghiệp lớn hay nhỏ bị ảnh hưởng hơn?
- Tìm từ khóa lặp lại nhiều nhất trong `confusion_during_onboarding`.

**Kỹ năng Antigravity luyện:** Phân tích văn bản tự nhiên, phân khúc dữ liệu.

### Phần 3: Phễu Chuyển đổi (10.000 users)
**File:** `activation-funnel-q4.csv`

Đây là phân tích **phễu (funnel)** — công cụ quan trọng nhất của PM:
- Tính tỷ lệ chuyển đổi qua 4 bước: Đăng ký → Tạo task → Hoàn thành task → Mời đồng đội.
- Bước nào mất người nhiều nhất? → **Đó là nút thắt cần tối ưu.**
- Vẽ biểu đồ phễu trực quan.

**Kỹ năng Antigravity luyện:** Xử lý dữ liệu lớn (10K dòng), phân tích funnel.

### Phần 4: Ước lượng Tác động (ROI)
**Files:** `taskflow-usage-data-q4.csv` + `impact-estimation-framework.md`

Biến phân tích thành **business case**:
- Kết hợp chỉ số kinh doanh (LTV, churn rate, cost) với framework.
- Tính ROI theo **3 kịch bản**: Bi quan, Thực tế, Lạc quan.
- Trả lời câu hỏi của CEO: "Nếu sửa Onboarding, đáng bao nhiêu tiền?"

**Kỹ năng Antigravity luyện:** Tham chiếu đa file (`@file1` + `@file2`), tính toán tài chính.

### Phần 5: Đóng gói Báo cáo HTML
Tổng hợp tất cả thành file HTML chuyên nghiệp gồm:
1. Executive Summary
2. Phân tích phễu chuyển đổi
3. Insight từ khảo sát
4. Ước lượng tác động 3 kịch bản
5. Đề xuất giải pháp

**Kỹ năng Antigravity luyện:** Tổng hợp đa nguồn, tạo HTML report.

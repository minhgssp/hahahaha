Module 1.3

Các tác vụ đầu tiên

Ba thao tác cốt lõi: Chỉnh sửa, Soạn thảo mới, và Tổng hợp thông tin.

⏱ 15-20 phút ▶️ Lệnh: /start-1-3

✏️ 1. Chỉnh sửa & Bổ sung (Append/Update)

Mục đích: Thêm tóm tắt, sửa lỗi, viết thêm nội dung vào file có sẵn.

Đọc @ten_file.md và thêm phần tóm tắt ở cuối file

Quy trình

  1. Antigravity đọc file
  2. Đề xuất nội dung mới
  3. Bạn xem xét và nhấn Accept (Chấp nhận)
  4. File gốc được cập nhật
Ví dụ: "Đọc @ghi_chu_cuoc_hop.txt và thêm mục 'Việc cần làm' vào cuối, liệt kê ai phải làm gì."

🔄 2. Soạn thảo Văn bản mới (Transform)

Mục đích: Biến ghi chú lộn xộn → Email chuyên nghiệp, Tờ trình, Công văn.

Đọc @file_nguon.md và tạo file mới tên file_moi.md định dạng theo [kieu_van_ban]

Quy trình

  1. Antigravity đọc file nháp/ghi chú
  2. Viết lại thành văn bản chỉn chu trong file mới
  3. File gốc giữ nguyên (để đối chiếu)
Ví dụ: "Đọc @y_tuong_tiec.txt và tạo file mới ke_hoach_tiec.md, trình bày dưới dạng tờ trình gửi Sếp."

📊 3. Tổng hợp thông tin (Synthesize)

Mục đích: Đọc nhiều file → 1 báo cáo tổng hợp duy nhất.

Phân tích tất cả file trong thư mục @ten_thu_muc và tạo file bao_cao_tong.md

Quy trình

  1. Antigravity đọc toàn bộ file trong thư mục
  2. Tìm các điểm chung, con số quan trọng
  3. Viết ra một báo cáo tóm tắt duy nhất

🔍 Quy trình Duyệt/Sửa với AI

AI sẽ không tự ý sửa file ngay. Luôn đi qua bước kiểm duyệt:

  1. Đề xuất: AI hiện ra bản nháp (phần thêm mới có màu xanh)
  2. Xem xét: Bạn đọc lướt qua
  3. Quyết định:

✅ Ưng ý?

Nhấn Accept hoặc Ctrl+Enter

❌ Chưa ổn?

Gõ thêm lệnh: "Viết ngắn gọn hơn" hoặc nhấn Reject

💡 Bí quyết ra lệnh (Best Practices)

Hãy cụ thể

❌ Mơ hồ

"Viết cái này hay hơn."

✅ Cụ thể

Luôn cung cấp ngữ cảnh

❌ Thiếu

"Làm báo cáo đi."

✅ Đủ

"Đọc @so_lieu_thang_5.xlsx và @nhan_xet.txt rồi tạo báo cáo tổng kết tháng."

⛽ Phần 2: Nhiên liệu của AI

1. Markdown (.md) — Ngôn ngữ của AI

Bạn đang đọc file Markdown! Đây là văn bản thuần túy (Plain Text).

✅ Tại sao AI yêu Markdown?

  • Đọc siêu nhanh: Nhanh gấp 10 lần file Word
  • Không lỗi định dạng: Không vỡ font, nhảy trang
  • Linh hoạt: Xuất ra PDF, HTML, Slide dễ dàng

⚠️ File Word (.docx)

  • Mã định dạng ẩn phức tạp
  • AI đọc chậm, dễ lỗi
  • Copy paste hay vỡ format

📊 Excel vs CSV & PDF

Tiêu chí Excel (.xlsx) CSV (.csv)
Bản chất Phần mềm phức tạp (Màu, Công thức) Dữ liệu thô (Chỉ số và chữ)
Tốc độ AI Chậm, dễ lỗi đọc Siêu tốc
Khi nào dùng? Gửi Sếp xem, in ấn Gửi AI phân tích dữ liệu lớn

📄 PDF (.pdf) — Kho lưu trữ đóng băng

✅ Đọc & Trích xuất

Antigravity đọc PDF rất tốt

🗂️ Phần 3: Thao tác File Cơ bản

Thao tác Chuột Ra lệnh AI
Tạo File Mới Chuột phải → New File → đặt tên "Tạo file mới tên ke_hoach.md"
Đổi Tên Chuột phải → Rename "Đổi tên file nhap.txt thành chinh_thuc.md"
Xem trước Bấm biểu tượng kính lúp —
Xóa File Chuột phải → Delete "Xóa file test.txt" ⚠️ Cẩn thận!

📋 Tóm lại

  1. Giao diện: Chat để ra lệnh, Sidebar để quản lý file, Editor để sửa
  2. Định dạng: Văn bản → Markdown | Dữ liệu → CSV | Tham khảo → PDF
  3. Thao tác: Tạo, Sửa, Xóa, Đổi tên — Bạn là chủ nhân kho dữ liệu

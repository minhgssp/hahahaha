Mở Thư mục Khóa học

Việc này giống như bạn mở một quyển sách ra để bắt đầu đọc vậy.

⏱ 5 phút 📋 Đã cài Antigravity (Module 0.2)

📂 Hướng dẫn từng bước

Bước 1: Tìm nút "Open Folder"

  1. Nhìn lên góc trên cùng bên trái → menu File
  2. Chọn Open Folder...
  3. Hoặc phím tắt: Ctrl+K rồi Ctrl+O (Windows) | Cmd+O (Mac)

Bước 2: Chọn thư mục Khóa học

  1. Tìm đến nơi lưu khóa học (thường trong Downloads hoặc Documents)
  2. Chọn thư mục antigravity_course_vn
  3. Nhấn Select Folder (hoặc Open)

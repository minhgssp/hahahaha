Cài đặt & Thiết lập
Antigravity dễ dàng

Đơn giản như cài Zalo hay Microsoft Office. Bạn không cần biết code!

⏱ 15 phút 📋 Máy tính Windows hoặc Mac

🪟 Cài đặt trên Windows

  1. Tải xuống: Truy cập antigravity.google/download → chọn Windows
  2. Cài đặt: Mở file .exe vừa tải về → nhấn "Next" liên tục
  3. Khởi động: Click đúp vào biểu tượng Antigravity trên Desktop

🍎 Cài đặt trên Mac

  1. Tải xuống: Chọn Apple Silicon (M1/M2/M3) hoặc Intel
  2. Cài đặt: Kéo biểu tượng vào thư mục Applications
  3. Khởi động: Tìm trong Launchpad và mở lên

🖥️ Làm quen Giao diện

Giao diện giống phần mềm chat (Messenger/Slack) kết hợp trình soạn thảo văn bản (Word).

1. Đăng nhập (Tùy chọn)

Đăng nhập bằng Google để đồng bộ, hoặc bấm "Skip" để dùng luôn.

2. Chọn Giao diện (Theme)

☀️ Light Mode (Sáng)

Giống Word/Excel, dễ nhìn văn bản. Khuyên dùng cho người mới.

🌙 Dark Mode (Tối)

Dịu mắt, dân công nghệ hay dùng. Phù hợp làm việc ban đêm.

3. Cửa sổ lệnh (Terminal)

Ô ở dưới cùng để gõ lệnh. Đừng sợ! Bạn chỉ cần gõ tiếng Việt đơn giản.

📂 Tạo Thư mục Làm việc (Workspace)

  1. Tại màn hình chính, chọn "Open Folder" (Mở thư mục)
  2. Tạo thư mục mới, đặt tên Khoa_Hoc_Antigravity
  3. Chọn thư mục đó → Bạn đã có "bàn làm việc" sạch sẽ!

🔧 Xử lý Sự cố Thường gặp

⚠️
"Máy báo phần mềm không an toàn"
• Windows: Bấm "More Info" → "Run Anyway"
• Mac: System Settings → Privacy & Security → Allow Antigravity
Phần mềm từ Google nên bạn yên tâm tuyệt đối.
⌨️
"Không gõ được tiếng Việt"
Đảm bảo đã bật Unikey ở chế độ "Run as Administrator" nếu bị lỗi.
